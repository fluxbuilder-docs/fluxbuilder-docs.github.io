Create a Native App for Your Website

Is this you?​

  • You already run a website or online store.
  • You want a full app with your own design, not just a webview app.
  • You want Native Apps for iOS, Android, and PWA in Hours - No Coding Required.

Your website is built on one of the following platforms:

  • E-commerce site — WooCommerce (single-vendor or multivendor stores using WCFM or Dokan), Shopify, Magento, OpenCart, PrestaShop, BigCommerce, Strapi, or Haravan.
  • Listing or Booking site — for properties, businesses, travel, or classifieds, powered by [Problem Internal Link], [Problem Internal Link], or [Problem Internal Link].
  • Delivery Boy and Admin (Manager) apps — for single-vendor or multivendor stores using WCFM or Dokan.
  • WordPress site (not e-commerce — blog, news, music, recipe, etc.), or want to build AI apps support ChatGPT & OpenAI.

Not sure what your platform is? Ask whoever manages your website, or check the admin login page — it usually shows the platform name.

Want your website to load inside an app, exactly as it looks now, with no extra design work? Go to Create a WebView App instead.

Don't have a website at all? Go to Create an App Without a Website.

Create with AI​

  • This guide shows you how to use AI to create and build your Native app faster.
  • Choose one of the two methods to create your Native app: “Create with AI” or “Create Manually” (below).

Follow these steps to take you from connecting your website to build and publish apps on the App Store and Google Play:

Step 1: Prepare your website​

To ensure that all products and images from your website are displayed correctly on your iOS and Android apps and that data stays synchronized, install the required plugins and complete the necessary configurations on your website.

Pick one guide that matches your site:

  • WooCommerce API Setup Guide
  • Shopify Access Token Guide
  • Opencart API Setup Guide
  • Magento API Setup Guide
  • PrestaShop API Setup Guide
  • Strapi API Setup Guide
  • Listing API Setup Guide
  • Delivery Boy API Setup Guide
  • Admin (Manager) API Setup Guide
  • WordPress API Setup Guide — for WordPress site (not e-commerce — blog, news, music, recipe, etc.)
  • OpenAI- Setup Supabase Server — want to build AI apps support ChatGPT & OpenAI (or FluxGPT app)
  • Other sites do not require installing API.

Create Manually​

  • This guide shows you how to create a Native app using the standard FluxBuilder workflow.
  • Choose one of the two methods to create your Native app: “Create Manually” or “Create with AI” (above).

Follow these steps to take you from connecting your website to build and publish apps on the App Store and Google Play:

Step 1: Prepare your website​

To ensure that all products and images from your website are displayed correctly on your iOS and Android apps and that data stays synchronized, install the required plugins and complete the necessary configurations on your website.

Pick one guide that matches your site:

  • WooCommerce API Setup Guide
  • Shopify Access Token Guide
  • Opencart API Setup Guide
  • Magento API Setup Guide
  • PrestaShop API Setup Guide
  • Strapi API Setup Guide
  • Listing API Setup Guide
  • Delivery Boy API Setup Guide
  • Admin (Manager) API Setup Guide
  • WordPress API Setup Guide — for WordPress site (not e-commerce — blog, news, music, recipe, etc.)
  • OpenAI- Setup Supabase Server — want to build AI apps support ChatGPT & OpenAI (or FluxGPT app)
  • Other sites do not require installing API.

Step 2: Create an app project​

tip

Create a new app project in FluxBuilder. Follow this guide to install and run FluxBuilder in your devices successfully.

✨ If using the FluxBuilder Desktop version, open FluxBuilder, then select Dashboard > choose Create New App: (If you subscribed to a plan but haven't created an app yet, refer to this guide.)

✨ If using the FluxBuilder Web version https://web.fluxbuilder.com : select Dashboard, click URL, then enter your Website URL and click Generate App: (If you subscribed to a plan but haven't created an app yet, refer to this guide.)

—-

Then, (1) Enter your Website URL or IP address of the HOSTING service (e.g. https://1.100.67.68) → (2) Select your site platform → (3) Enter the required information based on the selected platform → (4) Scroll down and click Run Troubleshoot → (5) If any item fails, click the ? icon to see how to fix it → (6) Select NEXT:

📌 At (2), if you're not sure which item to choose, see:

  • Listing or Booking site — [Problem Internal Link], [Problem Internal Link], or [Problem Internal Link] → Select the Listing item
  • WordPress (not e-commerce — blog, news, music, recipe site) → Select the WordPress item
  • Want to build AI apps support ChatGPT & OpenAI → Select the ChatGPT & OpenAI item
  • Delivery Boy and Admin (Manager) apps — for single-vendor or multivendor stores using WCFM or Dokan → Select the Delivery Boy or Manager item
  • E-commerce site: WooCommerce (single-vendor or multivendor stores using WCFM or Dokan), Shopify, Magento, OpenCart, PrestaShop, BigCommerce, Strapi, or Haravan → Select the related platform

—-

Select a Template and click NEXT:

📌 Note: The Delivery Boy and Admin (Manager) apps do not support UI customization in the FluxBuilder app builder. You can skip this step.

—-

Next, enter your app information:

  • App Name (required): Enter the name of your App.
  • Short Description (optional): Enter a brief description of your app.
  • Upload Logo (optional): Upload your app logo for both Light and Dark themes. You can change it later.

Choose a color, font, and default Light/Dark theme (optional — you can edit these settings later). Then click CREATE APP :

Your app project has been created successfully and this is the FluxBuilder editor:

Step 3: Customize your app​

Customize your app’s UI and features by drag-and-drop on FluxBuilder to create an experience that fits your needs.

👉 Learn how to customize your app

Step 4: Build Apps and Release​

Once your app UI and features are ready, it’s time to build, test, and release your app.

  • Generate Demo App for Free and test on phone.
  • Build and Publish Apps on both Google Play and App Store.

🎉 You’re all set! Your app is ready to launch.
